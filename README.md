# Ontogenesis HealthOS

Modular, AI-native healthcare and life-sciences software platform by Ontogenesis Technologies Pvt. Ltd.

> **Status: Milestone M0 (discovery & architecture) — awaiting approval.**
> No runnable code exists yet. Nothing in this repository is certified, validated, or approved for real patient data.

## Products

| Product | Purpose | Standalone? |
|---|---|---|
| **HealthOS Core** | Shared platform: identity, tenancy, licensing, configuration, audit, documents, workflows, AI gateway | Required by all products |
| **CareOps Quality AI** | Controlled documents, SOPs, deviations, CAPA, training | Yes |
| **ClinicOS AI** (+ Dental, Vision packs) | Outpatient clinic management | Yes |
| **HospitalOS AI** | Hospital management modules (later release train) | Yes |
| **MedTechOS AI** | Medical equipment lifecycle and service (later release train) | Yes |
| **HealthConnect** | Integration platform (FHIR, HL7 v2, REST) | Optional add-on |
